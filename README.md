# Furkan Saribal Portfolio

Personal portfolio website for my game development work, jam experience, and technical focus areas.

https://furkansaribal.github.io/

## Overview

This portfolio brings together:

- selected game projects
- game jam experience
- technical focus areas such as character control, gameplay programming, and level design
- public links for contact and project browsing

## Features

- pixel-art inspired interface
- Turkish / English language toggle
